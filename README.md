# Освітні анімаційні інтерактиви («кінозал»)

Колекція коротких озвучених анімацій-симуляторів зі складних тем дискретної математики та теорії алгоритмів. Кожен анімаційний інтерактив — **один самодостатній HTML-файл**: без встановлення, без зовнішніх бібліотек, відкривається у звичайному браузері. Тему подано не як «текст і формули», а як історію, що розгортається на екрані: сцена за сценою, з голосом, підписами і (у деяких випадках) грою-завданням у фіналі.

Колекція поповнюється, тому актуальний перелік дивіться в каталозі (`index.html`) або просто в списку файлів репозиторію.

## Як запустити

**Один анімаційний інтерактив.** Завантажте потрібний `.html` і відкрийте його в браузері подвійним кліком. Натисніть на екран, щоб почати.

**Каталог.** `index.html` отримує список файлів через GitHub API і читає самі анімації, тому з `file://` не працюватиме. Є два шляхи:

- опублікувати репозиторій через GitHub Pages (Settings → Pages → Deploy from a branch) і користуватися каталогом за посиланням;
- або запустити локальний сервер у папці з файлами:

```bash
python -m http.server 8000
# потім відкрийте http://localhost:8000/
```

## Керування плеєром

| Дія | Як |
|---|---|
| Грати / пауза | кнопка ▶ або `Пробіл` |
| Попередня / наступна сцена | кнопки ⏮ ⏭ або `←` `→` |
| Зупинити й повернутися на початок | кнопка ■ або `R` |
| Перемотка | клік по шкалі часу; клік по засічці переходить на початок сцени |
| Швидкість | вибір 0,75× … 1,5× (діє і на анімацію, і на голос) |
| Субтитри | прапорець «Субтитри» (типово вимкнені) |
| Назви сцен | прапорець «Назви сцен» показує підписи під засічками шкали |
| Транскрипт | прапорець «Транскрипт»: під плеєром з'являється повний текст озвучення по сценах, клік на сцену переходить до неї |

## Шаблон анімаційного інтерактиву

Усі анімаційні інтерактиви збудовано за однаковим шаблоном. Завдяки цьому нову тему можна зробити, не чіпаючи плеєр, а студія озвучення працює з будь-яким файлом без налаштувань.

### Із чого складається файл

Файл поділяється на шари, які йдуть у такому порядку:

1. **Розмітка й стилі.** Контейнер `.presentation` з полотном `<canvas id="canvas">`, елементами субтитрів і індикатора сцени, панель керування (кнопки, шкала часу, перемикач озвучення, швидкість, прапорці) і блок транскрипту.
2. **Допоміжні функції малювання.** Плавні переходи, написи, виноски, ефекти (див. нижче).
3. **Функції сцен** `s0`, `s1`, … — по одній на сцену.
4. **Масив `scenes`** — опис сцен: назва, тривалість, текст озвучення, функція малювання.
5. **Блок `VOICE`** (лише в озвучених файлах, його додає студія).
6. **Модуль `Game`** (лише в анімаціях із грою у фіналі).
7. **Озвучення** — вибір рушія, синтез мовлення, відтворення mp3.
8. **Плеєр** — навігація між сценами, перемотка, пауза.
9. **Головний цикл** — на кожному кадрі оновлює час, малює поточну сцену й керує переходами.

### Опис сцени

```js
const scenes=[
 {tick:'Хук', dur:26, draw:s0, text:"Текст, який озвучує диктор."},
 // ...
 {tick:'Гра', dur:14, noSub:true, isGame:true, draw:function(){Game.frame()}, text:"Ваша черга!"}
];
```

| Поле | Призначення |
|---|---|
| `tick` | Коротка назва сцени. Її видно на шкалі й у транскрипті, а ще з неї утворюється ім'я mp3-файлу, тому назви сцен в одному файлі мають бути різними й змістовними |
| `dur` | Тривалість анімації в секундах |
| `text` | Текст озвучення. Він же стає субтитрами й транскриптом. У субтитри текст вставляється як HTML, тож символи `<` та `&` у ньому треба екранувати |
| `draw` | Функція малювання сцени `draw(w, h, st, gt)` |
| `noSub` | `true`, якщо для цієї сцени субтитри не потрібні (наприклад, для гри) |
| `isGame` | `true` для сцени-гри (див. нижче) |

### Функція малювання

Сигнатура функції сцени — `s(w, h, st, gt)`:

- `w`, `h` — розмір полотна;
- `st` — секунди від початку **цієї** сцени;
- `gt` — секунди від початку всієї анімації (для фонових ефектів, що не залежать від сцени).

Мінімальна сцена:

```js
function s0(w,h,st){
  sceneTitle('Заголовок сцени',st);        // заголовок з підкресленням
  const a=eo(stag(st,1,0.8));              // від 0 до 1 між 1,0 і 1,8 с
  chip('перший підпис',w/2,h*0.5,a);       // виноска, що поступово з'являється
}
```

Головне правило: **малюнок має повністю визначатися часом `st`**, без накопиченого стану між кадрами. Тоді перемотка працює будь-куди: плеєр просто задає потрібне `st` і сцена малюється так, ніби вона йшла від початку. Перші 0,45 с кожної сцени плеєр сам накладає напівпрозору завісу, що зникає, тож окремо про перехід дбати не потрібно.

Розміри шрифтів і ліній множать на коефіцієнт масштабу `K` (функція `fnt(px)` робить це сама), щоб сцена виглядала однаково на екранах різного розміру.

### Допоміжні функції

Набір у різних файлах трохи відрізняється, але ядро спільне:

| Група | Функції |
|---|---|
| Час і плавність | `stag(t, початок, тривалість)` повертає 0…1, `eo`, `eio`, `eob` (плавні криві), `lerp`, `clamp`, `rnd` |
| Текст | `fnt`, `txt`, `sceneTitle`, `chip`, `caption` (друкарський ефект), `card`, `rr` (прямокутник із заокругленням) |
| Ефекти | `stamp` (печатка), `shock` (хвиля), `confetti`, `hearts` |
| Графіка | `arrowHead`, `curveArrow`, `pointer`, `node`, `edge` та інші фігури, потрібні конкретній темі |

### Як сцени змінюють одна одну

Плеєр переходить до наступної сцени, коли виконано дві умови: анімація відпрацювала `dur` секунд **і** озвучення закінчилося. Після цього робиться пауза 0,7 с. Тому:

- якщо голос довший за `dur`, сцена дочекається його кінця (щоб не завис звук, є запобіжник: `dur` + 30 с для Web Speech і `dur` + 60 с для інших рушіїв);
- якщо голос коротший, сцена спокійно дограє анімацію;
- найкраще виставляти `dur` ≈ довжина озвучення + 1 с. Студія робить це автоматично для записаного голосу.

### Сцена-гра

Фінальна сцена з інтерактивним завданням має `isGame:true`, `noSub:true` і `draw:function(){Game.frame()}`. Модуль `Game` — це окремий блок усередині файлу зі своїм полотном `#gameCanvas` і панеллю (заголовок, завдання, кнопки «Підказка», «Крок назад», «Спочатку», рядок стану). Він показується поверх анімації, коли активна сцена-гра, і приймає дії мишею чи дотиком. Набір кнопок залежить від теми (підказка, крок назад, скидання, показ відповіді), але логіка підтримки студента спільна: миттєва реакція на помилки, підказка і кілька рівнів складності.

## Озвучення

Текст кожної сцени (`text`) озвучується або синтезатором мовлення, або записом диктора. У панелі керування є перемикач рушія: UA нейро, Web Speech, Google TTS, Тихо.

### Синтез мовлення

| Рушій | Як працює | Примітки |
|---|---|---|
| **Google TTS** (типово) | Текст сцени ріжеться за реченнями на шматки до 180 символів, шматки звучать по черзі. Використано неофіційні ендпоінти `translate.google.com` і `translate.googleapis.com` | Потрібен інтернет. Якщо звук не стартує за 6 с або сервіс недоступний, плеєр сам переходить на Web Speech |
| **Web Speech** | Голос, вбудований у систему чи браузер, швидкість = 0,95 × вибрана | Потрібен український голос в ОС. Якщо його немає, плеєр вмикає режим «Тихо» й попереджає |
| **UA нейро** | Українська нейромережа (демо `robinhad/ukrainian-tts` на Hugging Face). Текст ріжеться на шматки до 110 символів, поточна й наступна сцени синтезуються наперед, результати кешуються. Голоси: Тетяна, Лада, Дмитро, Микита, Олекса | Потрібен інтернет. Поки голос готується, анімація чекає, а на екрані напис «Готую озвучення…». Якщо сервіс недоступний, плеєр переходить на Google TTS |
| **Тихо** | Без звуку, лише анімація й субтитри | |

Швидкість (0,75× … 1,5×) змінює і хід анімації, і темп голосу.

### Озвучення живим голосом (mp3)

Для кращої якості анімацію можна озвучити диктором. Записані файли підключаються через блок `VOICE`, який додає студія:

```js
const VOICE=[
  {"tick":"Хук","file":"gray-code-hypercube-khuk.mp3?v=mvgy73td","dur":27.59},
  // ...
];
```

Як це працює:

- **Пріоритет.** Якщо для сцени є запис, звучить він, а не синтез. Сцени без запису озвучує вибраний рушій, тож озвучувати можна поступово.
- **Збій одного файлу.** Якщо mp3 не знайдено чи він не відтворюється, лише ця сцена переходить на синтез, решта лишаються з живим голосом.
- **Зв'язок за назвою сцени.** Запис шукається за `tick`, а не за номером, тож перестановка сцен у масиві нічого не ламає.
- **Тривалість.** Поле `dur` у `VOICE` — довжина запису. Якщо запис довший за анімацію, тривалість сцени подовжується до довжини запису плюс 1 с.
- **Кеш.** До імені файлу додається `?v=…` (ідентифікатор запису), тому після перезапису браузер і хостинг віддають нову версію.
- **Швидкість, пауза, перемотка.** Швидкість діє і на mp3, пауза зупиняє голос разом з анімацією, а перемотка по шкалі ставить озвучення на ту саму позицію всередині сцени.

**Імена файлів.** Усі mp3 лежать в одній папці з HTML і називаються `префікс-назва-сцени.mp3`. Префікс походить від імені файлу анімації (його можна змінити в студії), назва сцени береться з `tick` і транслітерується за українською національною таблицею: усе латиницею в нижньому регістрі, через дефіс. Приклад: сцена «Фінал» в анімації про код Грея дає `gray-code-hypercube-final.mp3`.

## Студія запису озвучення

`_studio.html` автоматизує роботу диктора: читаєш сцену, натискаєш стоп, і програма сама робить mp3 з правильним ім'ям та оновлює анімаційний інтерактив. Усе відбувається у браузері, файли нікуди не надсилаються.

**Де відкривати.** Локальний сервер не обов'язковий. Мікрофон потребує захищеного з'єднання, а його дає `https`, тож достатньо відкрити студію з опублікованого сайту (наприклад, з GitHub Pages). Лише з `file://` браузер може не дати доступ до мікрофона або щоразу перепитувати дозвіл. Якщо студія відкрита в незахищеному контексті, вона покаже попередження.

### Порядок роботи

1. Відкрийте студію й перетягніть у неї **вихідний** HTML-файл анімаційного інтерактиву (студія не приймає вже озвучений файл).
2. Оберіть сцену зі списку праворуч. Диктор бачить анімацію та великий текст-телесуфлер (розмір шрифту змінюється кнопками A− A+).
3. Запис: `Пробіл` починає, `Пробіл` зупиняє, `Esc` скасовує. Типово перед записом іде відлік 3-2-1, а анімація сцени грає разом із диктором, щоб читати «в такт». Кнопки «Прослухати» і «Переписати» дозволяють відразу перевірити результат.
4. Студія сама обробляє запис: обрізає тишу на початку й у кінці (з невеликим запасом), вирівнює гучність, кодує в mp3 (моно, 96 кбіт/с, близько 0,7 МБ на хвилину). Кожну з цих дій можна вимкнути прапорцями.
5. Біля кожної сцени видно, чи вона записана, її тривалість і майбутнє ім'я файлу. Якщо запис помітно коротший за анімацію, студія про це попередить.
6. Коли все готово, натисніть **«Зберегти все»**.

### Що видає кнопка «Зберегти все»

- mp3 для кожної записаної сцени;
- оновлений анімаційний інтерактив із підключеним озвученням.

Варіанти збереження: у вибрану папку (Chrome, Edge), окремими файлами (будь-який браузер) або одним ZIP-архівом. Усі файли потім кладуть в одну папку на хості.

### Що змінюється в оновленому файлі

- підключається блок `VOICE` (див. вище);
- прапорець «Субтитри» вимкнений за замовчуванням;
- «Дебаг» перейменовано на «Транскрипт» і він показує не лише назви сцен, а й текст озвучення;
- швидкість діє і на mp3;
- пауза, відновлення та перемотка працюють з озвученням.

### Корисне

- **Нічого не втрачається.** Записи зберігаються в самому браузері, тож закрита вкладка їх не знищить. Після повторного завантаження того самого файлу записи повертаються.
- **Зміна тексту.** Якщо текст сцени змінили після запису, студія позначає сцену знаком «!» і просить її перезаписати. Якщо лише перейменували `tick`, запис перепідключається за збігом тексту.
- **Готові mp3** можна перетягнути у вікно студії, і вони підхопляться за іменем файлу. Так зручно перезаписувати окрему сцену: завантажте вихідний HTML, додайте наявні mp3, перепишіть потрібну сцену й знову натисніть «Зберегти все».
- **Зберігайте вихідний файл** без озвучення (наприклад, в окремій папці чи гілці): студія працює тільки з ним.
- **Фіналізуйте текст до запису.** Будь-яка правка `text` означає перезапис цієї сцени.

## Як додати власний анімаційний інтерактив

1. Скопіюйте найближчий за стилем файл і замініть функції сцен та масив `scenes` (див. [шаблон](#шаблон-анімаційного-інтерактиву)).
2. Перевірте його в браузері: перемотка, пауза, швидкість, субтитри.
3. Покладіть файл у репозиторій: каталог підхопить його автоматично. У форку змініть `OWNER` і `REPO` на початку скрипта в `index.html`.
4. За бажання озвучте його живим голосом у студії.

## Технічно

- Один файл на анімацію, чистий HTML + CSS + JavaScript, малювання на `canvas`.
- Зовнішні бібліотеки не потрібні. Інтернет знадобиться лише для озвучення Google TTS і UA нейро та для списку файлів у каталозі.
- Розраховано на сучасні браузери. Студію запису найзручніше використовувати в Chrome або Edge, бо лише вони пишуть файли прямо в папку.
